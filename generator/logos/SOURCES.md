# Logo sources

| File | Source | Notes |
| --- | --- | --- |
| `blender.svg` | https://github.com/blender/blender/blob/main/release/freedesktop/icons/scalable/apps/blender.svg | Blender's own application icon, full colour, unmodified. |
| `vscode.svg` | https://github.com/simple-icons/simple-icons (npm package `simple-icons@9.21.0`, CC0; later releases dropped it) | Community copy of the VS Code ribbon, drawn in VS Code's brand blue `#007ACC`. Microsoft's own three-tone icon is on https://code.visualstudio.com/brand and can replace this file (its repo only ships the generic Code - OSS icon). |
| `unrealengine.svg` | https://github.com/simple-icons/simple-icons/blob/develop/icons/unrealengine.svg | Community-maintained copy. Epic publishes its logo through https://www.unrealengine.com/en-US/branding and asks for a signed form first. Replace this file with the official one if you have it. |

Logos belong to their owners (Blender Foundation, Microsoft, Epic Games) and are shown only to say which tools are used.
