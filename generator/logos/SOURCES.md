# Logo sources

| File | Source | Notes |
| --- | --- | --- |
| `blender.svg` | Official Blender logo kit (blender.org/about/logo, `blender_logo.svg`) | Blender Foundation artwork, unmodified except that the "blender" lettering is removed and the view box is cropped to the icon. |
| `vscode.svg` | https://code.visualstudio.com/brand (official "stable" icon, `visual-studio-code-icons` archive dated 2021-06-21) | Microsoft's own three-tone icon, unmodified. Keeps its own colours on the loadout. |
| `unrealengine.svg` | Official Epic Games Unreal Engine brand assets (`UE-Icon-2023-White.svg`) | Epic's own white icon, unmodified. |

Logos belong to their owners (Blender Foundation, Microsoft, Epic Games) and are shown only to say which tools are used.

## Official language logos

| File | Source | Notes |
| --- | --- | --- |
| `kotlin.svg` | JetBrains Kotlin brand kit (`Kotlin Ecosystem Logos/Kotlin/Primary/Kotlin icon.svg`) | JetBrains' own gradient icon, unmodified. |

| `python.svg` | Python Software Foundation's "two snakes" logo (python.org/community/logos, `python-logo-only.png`, 269 px) | Not a vector: an SVG wrapper around the PSF PNG with its drop shadow trimmed. Replace with `python-logo-only.svg` from the same page if you get it. Trademark of the PSF. |
| `lua.svg` | https://github.com/devicons/devicon (`icons/lua/lua-original.svg`) | Vector of the official Lua logo (navy disc, orbiting moon, grey ring), in its original colours. lua.org/logo.html does not exist; the official artwork is under lua.org/images. |
